# Arbeidsregel: Start riktig etter pause

Når vi gjenopptar dette eller andre kodeprosjekter etter noen dagers pause, skal AI-assistenten først spørre brukeren: **«Skal jeg sjekke erfaringsloggen, endringsloggen og siste GitHub-status, slik at vi fortsetter der vi slapp?»**

Når brukeren bekrefter, skal assistenten lese dokumentert status og siste commits, kontrollere hvilket repository, gren og miljø som gjelder, og oppsummere hva som er implementert, verifisert og gjenstår. Ikke start feilsøking på nytt uten å undersøke tidligere arbeid. Ikke endre produksjon uten test og godkjenning. Avslutt vesentlige arbeidsøkter med logg over utført arbeid, faktisk testresultat og neste konkrete steg.

Denne regelen gjelder alle kodeprosjekter. For dette repositoryet: oppdater prosjektets eksisterende erfarings-/endringslogg ved videre arbeid.
